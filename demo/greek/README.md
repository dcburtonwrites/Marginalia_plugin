# Greek Demo vault

An original mythology-inspired Marginalia teaching vault, **The Pomegranate Accord**, prepared for direct download. The demo does not modify, copy or depend on a user vault.

Build after `npm run package` with `npm run demo:build`. `npm run release:prepare` builds/verifies it automatically and includes the download in the static website ZIP.

Outputs:

- `dist/greek-demo/Marginalia Greek Demo/`: ready-to-open vault, including hidden `.obsidian` configuration and Marginalia's three install files.
- `website/dist/downloads/marginalia-greek-demo-0.5.0.zip`: downloadable vault, with its named folder at the archive root.
- `dist/greek-demo-manifest.json`: generated note metadata and file hashes for verification.

Content: 72 Markdown notes (including templates and tours), 12 character profiles, four items, two affiliations, two systems, four locations, two calendars, 18 dated and two undated events, three First Draft comic scripts plus a Practice script (10 pages/10 panels), a project outline and five pinned Home walkthroughs. Twenty local SVG symbol icons accompany the timeline participants. All 20 participants have repeated appearances; Hermes connects three location lanes.

The illustrative chronology and original invented scenes are labeled throughout. Museum background and an ancient-source starting point are linked in the vault's Adaptation and sources note; no modern translation, stock portrait, private note, remote image or generated Librarian result is copied. The Harvest Ledger's prose contradiction and the Seasonal Compact's missing delay rule are intentional, labeled reasoning exercises. Technical timeline/reference diagnostics are otherwise clean.

Fresh settings configure World routes/templates, all modules, two colored location groups, the First Draft script scope, a 25-minute timer/300-word goal and a saved Home/timeline/sidebar layout. Model selection is blank. No Ollama model, secret, author email, personal history, machine path or trust bypass is bundled. Generated reports are not pre-seeded. MIT license is included.

Open the unzipped folder as a new vault, review Obsidian's first-open trust prompt, enable Marginalia, and reload if needed. Use Open Home if unknown plugin tabs were restored before activation. Native verification used a disposable `.preview/Greek Demo QA` copy rather than the distributable directory; runtime settings/cache changes must never be copied back into the downloadable vault. To reset, extract a fresh copy instead of overwriting edits.
