Validation: **185 automated tests** (119 pure/core + 66 host), typecheck and package pass. Desktop browser regression, Librarian citation/disclosure/source-link browser regression, and Node-unavailable mobile loading smoke pass. Native tests used only Marginalia Test Vault. New synthetic spacing/source and saved-artifact fixtures were added there; original files were preserved. Updated development files and ZIP are in `dist`.

[Local storage/timing result](librarian-storage-check.json) is generated by `scripts/check-librarian-storage.ts`. It copies only invented local data and measures 1,200 synthetic notes over 12 runs. These numbers are CPU-only retrieval/inventory measurements, not evidence of real-vault disk, Sync, Markdown-rendering or inference speed. Aggregate inference timing includes grounding review and its bounded correction when used.

Recovery limits: one prior plugin version, not a complete history. A failed first save has no prior version. Files without a valid plugin owner marker are never silently adopted, even when damaged; standalone ownership migration remains deferred. Adapter checks do not guarantee a cross-process atomic write. Only supported plugin recovery copies can be restored; unowned recovery bytes block replacement and remain intact.
